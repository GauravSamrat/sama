# Abundance Letters

Set newsletter.signup in studio.js to the verified HTTPS address of a provider-hosted signup form. The website exposes a signup link and sends no email addresses itself. While the address is empty, the local page explains availability.

Configure provider-side email validation, explicit newsletter consent, consent timestamps, double opt-in, deduplication, unsubscribe, error handling, export and deletion. Review its privacy notice, retention and cost before enabling it. Test with an opted-in address and confirm unsubscribe. Problem-sharing preferences never create subscribers.
